# Personal portfolio

A small static portfolio site, built with HTML and CSS and deployed to GitHub Pages.

## Portfolio content

The page is personalized with the name, location, education, skills, contact links, and experience and project details from Visakan's resume. The resume itself is not included in the published site. Review the public contact details and project descriptions before sharing.

## Publish with GitHub Pages

1. Push the repository to GitHub, with the site files on the `main` branch.
2. In the repository settings, open **Pages** and set the build and deployment source to **GitHub Actions**.
3. Push a commit to `main`, or run **Deploy portfolio to GitHub Pages** from the Actions tab.
4. Once deployment succeeds, GitHub Pages shows the public URL in the workflow deployment environment and repository **Pages** settings. For this repository it will typically be `https://visakan-sk.github.io/portfolio/`.

The included workflow publishes the repository root on pushes to `main` and can also be run manually.
